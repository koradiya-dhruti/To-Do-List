# To-Do-List
A persistent console-based to-do list application built in Python. The program allows users to add, view, and remove tasks. Tasks are stored in a text file to maintain data even after the program closes.

# Objective
A simple console-based to-do list manager built using Python.

# Features
- Add tasks
- View tasks
- Remove tasks
- Persistent storage using text file
- Error handling

# Technologies Used
- Python 3
- VS Code
- Terminal

# How to Run
1. Open terminal
2. Navigate to project folder
3. Run:
   python todo.py
